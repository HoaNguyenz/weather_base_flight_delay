Overview
This project analyzes and visualizes U.S. flight delay patterns from 2019 to 2023 using the Flight Delay & Cancellation Dataset. It includes:
- Delay trends by airline, origin/destination airports
- Weather impact on delays
- Top airports with high/low delay rates
- Summary metrics and visual dashboard

Key Visualizations
- Top 5 Airports with Highest Delay Rates
- Top 5 Airports with Lowest Delay Rates
- Delay Distribution by Day of Week
